# SolatTime

SolatTime is a desktop application developed using Electron and JavaScript. It helps users view daily prayer times and manage personal reminders.

## Features
- Display daily prayer times based on selected location.
- Identify the upcoming prayer.
- Suggest activities based on the time remaining before the next prayer.
- Add, edit and delete personal reminders.
- Store reminders locally using Local Storage.

## Technologies Used
- HTML
- CSS
- JavaScript
- Electron
- Solat.my API

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Run `npm install`.
4. Run `npm start`.
